## Verified locally

Keycloak is running in a local Docker container, published only on
`127.0.0.1:8843`. It uses a pinned SUSE BCI OpenJDK image and a Keycloak
distribution verified against the SHA256 digest on its upstream release.

The test performs password login for each synthetic user. It does not send
owner/product values in the login request. Keycloak reads those values from
administrator-managed user attributes and inserts them into the signed SAML
response through the configured mappers.

| User | Automatically assigned owner | Automatically assigned product | Signed response verified |
| --- | --- | --- | --- |
| Alice | `lab-sso-alice` | `lab-sso-product-a` | Yes |
| Bob | `lab-sso-bob` | `lab-sso-product-b` | Yes |
| Untagged | Absent | Absent | Yes |

The verifier checks the metadata signing certificate, issuer, audience, NameID
and attribute values. Keycloak's persisted user-profile configuration restricts
editing `owner`/`product` to administrators.

Sanitized evidence is saved in `artifacts/sso-idp/login-verification.json`.
SAML assertions, passwords and tokens are not included in committed evidence.
